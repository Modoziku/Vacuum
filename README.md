# 🌀 Vacuum — Username Scanner

Vacuum — это быстрый и умный сканер юзернеймов для Telegram и Fragment. Находит свободные, оценивает их редкость и выводит результат в реальном времени. Работает без API, без регистрации, полностью анонимно через парсинг.

## 🚀 Возможности

- 🔍 Поиск юзернеймов от 5 до 16 символов.
- 🎯 Фильтр по ключевым словам (например, `moon`, `dark`, `god`).
- 🔢 Опция "только буквы" или "буквы + цифры".
- 💎 Оценка редкости: `COMMON`, `UNCOMMON`, `RARE`, `LEGENDARY`.
- 🌈 Цветной вывод в консоли (Colorama):
  - Белый — Common
  - Зелёный — Uncommon
  - Синий — Rare
  - Жёлтый — Legendary
- 📂 Автосохранение находок в `free_usernames.txt`.
- 🔄 Бесконечный режим сканирования (остановка по Ctrl+С)
